# Ferramenta TIA Portal Openness — Guia de uso e introdução (v2.0)

## Um. O que é

Uma ferramenta para automatizar projetos Siemens **TIA Portal**: conectar ao TIA, criar projetos, adicionar hardware (PLC / WinCC Unified HMI), gerar programas PLC (UDT / Global DB / tabela de tags / SCL / LAD), gerar telas e variáveis HMI, compilar, diagnosticar e salvar — tudo por IA ou um único comando.

Usa a única interface pública oficial da Siemens, **Openness**, e oferece suporte ao TIA Portal V20 e V21.

### Ainda é “apenas MCP”? — não

Desde a **v2.0**, o mesmo executável possui dois modos:

| Modo | Usuário | Acionamento | Cenário |
|---|---|---|---|
| **Serviço MCP** | Clientes de IA compatíveis com MCP | Iniciar sem subcomando; o cliente usa MCP | Desenvolvimento conversacional no IDE |
| **CLI `tia`** | Pessoas ou qualquer IA | `tia gen spec.yaml` etc. | Criar/alterar projetos, lotes, BAT e CI |

Em resumo: **MCP é ideal para interação conversacional; CLI é ideal para uma spec e um comando**. A capacidade é a mesma.

## Dois. Início rápido

### Modo A: serviço MCP

Configure o `command` para o executável. O pacote Release usa `tools\...\bin\Release` (V21) ou `bin-v20\Release` (V20); clones Git usam `runtime\v21`. O arquivo `配置MCP.bat` pode fazer o registro automaticamente.

Locais comuns: Cursor `.cursor/mcp.json`, VS Code `.vscode/mcp.json`, Claude Desktop `%APPDATA%\Claude\claude_desktop_config.json` e Claude Code `claude mcp add`/`~/.claude.json`.

### Modo B: CLI `tia`

Adicione a raiz do pacote ao `PATH` e use:

```text
tia gen   projeto.yaml --dry-run
tia patch alterações.yaml
tia compile D:\proj\X.ap21 --plc PLC_1
tia describe D:\proj\X.ap21 --plc PLC_1
tia prewarm
tia schema
```

Códigos de saída: 0 = sucesso, 1 = etapas com falha, 2 = erro. Use `--json` para saída legível por máquina.

### Modo C: clique duplo

Arraste `spec.yaml`/`spec.json` para `scripts\生成工程.bat`. Para acelerar, execute antes `scripts\预热.bat`.

## Três. Formato da spec

Uma YAML ou JSON descreve o projeto e é usada por `tia gen`, `tia patch` e `ScaffoldProject`. Consulte `tia schema`, `templates/project-blueprints/` e `docs/AI_spec_prompt.md`.

## Quatro. O que pode ser criado

- Hardware: PLC S7-1200/1500 e WinCC Unified HMI opcional, com conexão automática HMI↔PLC.
- Programa PLC: UDT, Global DB, tabelas de tags, blocos SCL externos e LAD em S7DCL.
- HMI: telas Unified na resolução nativa, variáveis, vinculações e dinamizações.
- Compilação/diagnóstico/salvamento, exportação/importação, estado online, textos de alarme e OPC UA.

## Cinco. Perguntas frequentes

- A primeira conexão headless leva cerca de 10–28 s; `tia prewarm` reduz as seguintes para cerca de 1 s.
- Use o executável correspondente à versão principal do TIA: V21 (`bin\Release`) ou V20 (`bin-v20\Release`).
- Use `--with-ui` para iniciar com interface completa.
- Saída UTF-8; arquivos `.scl` devem usar UTF-8 com **BOM**.
- Caminhos relativos são resolvidos a partir do diretório atual.
- Use a resolução nativa do painel em `width/height` (por exemplo, 800×480 ou 1280×800).
- Em `hmiTags`, prefira endereços absolutos (`%M..` / `%DB..`).
