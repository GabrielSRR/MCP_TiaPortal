# Guia de leitura de valores online em tempo real

Este guia descreve como ler valores atuais do PLC com segurança, sem escrever valores, forçar variáveis ou alterar o modo da CPU.

## Princípios de segurança

- Use ferramentas somente leitura.
- Confirme primeiro a identidade e o IP da CPU.
- Use `expectModuleContains` como proteção contra o PLC errado.
- Nunca confunda leitura online com download ou força.
- Ao usar TIA Openness, coloque o PLC offline ao terminar o monitoramento.

## Fluxo recomendado

1. `GetProjectTree` para obter o `softwarePath`.
2. `GetDeviceIpAddress` para ler o IP configurado.
3. `ProbeS7CpuIdentity` para confirmar tipo, série e identidade.
4. Escolha `ReadPlcLiveValuesS7` para endereços absolutos ou `ReadPlcLiveValuesOpcUa` para símbolos.
5. Para séries temporais, use `SamplePlcLiveValuesS7`.
6. Para uma watch table existente, use `MonitorWatchTableLiveS7` ou `ReadPlcWatchTableCurrentValuesReadOnly`.

## S7 direto

`ReadPlcLiveValuesS7` usa ISO-on-TCP, porta 102, e lê endereços como `DB10.DBD0:REAL`, `DB1.DBX2.3`, `M0.0`, `MW12` e `DB5.DBD8:DINT`. Em S7-1200/1500, habilite `Permit PUT/GET access` e use DBs não otimizados. M/I/Q não têm essa restrição.

## OPC UA

`ReadPlcLiveValuesOpcUa` usa `opc.tcp`, normalmente na porta 4840, com sessão anônima somente leitura. O servidor OPC UA precisa estar habilitado e as variáveis expostas; em S7-1200/1500 pode ser necessária licença Runtime.

## Diagnóstico causal

`TraceTagCause` identifica offline quais redes escrevem uma tag e quais condições as habilitam. `TraceTagCauseLive` complementa isso lendo ao vivo as condições resolvíveis por endereço S7. Membros de DB otimizado ou símbolos sem endereço absoluto podem exigir OPC UA.

## Estado da CPU

`GetPlcRunStateS7` lê RUN/STOP/UNKNOWN, relógio e um diagnóstico bruto. A API pública do Openness não expõe o modo da CPU; não use `GetOnlineState` para inferir RUN/STOP.

## Limitações

As ferramentas de leitura nunca escrevem, forçam valores, alteram watch tables ou mudam o modo da CPU. Antes de qualquer download, use as verificações específicas de compilação e prontidão; download é uma operação separada e altera o comportamento da máquina.
